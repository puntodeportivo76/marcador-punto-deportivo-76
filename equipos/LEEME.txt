PUNTO DEPORTIVO 76 — OVERLAY DE PRESENTACIÓN DE EQUIPOS

ARCHIVOS
- overlay-equipos.html: página transparente para agregar como fuente web en Larix.
- control-equipos.html: panel para manejar desde el segundo celular.
- LEEME.txt: estas instrucciones.

IMPORTANTE
Este paquete es complementario. No reemplaza ni modifica index.html, el marcador actual ni el control de marcador.
Usa una ruta nueva de Firebase Realtime Database: teamIntroOverlay.

PUBLICACIÓN SUGERIDA EN GITHUB PAGES
1. En el repositorio actual, crea una carpeta nueva llamada equipos.
2. Sube dentro los dos HTML con sus nombres exactos.
3. No reemplaces index.html ni archivos del marcador/publicidad.
4. Espera a que GitHub Pages publique la carpeta.

URLS (reemplaza USUARIO y REPOSITORIO por los datos de tu GitHub):
- Overlay Larix: https://USUARIO.github.io/REPOSITORIO/equipos/overlay-equipos.html
- Control segundo celular: https://USUARIO.github.io/REPOSITORIO/equipos/control-equipos.html

CONFIGURACIÓN FIREBASE NECESARIA
El overlay usa inicio de sesión anónimo para leer teamIntroOverlay; el panel usa el inicio de sesión de administrador ya existente.
En Firebase Console:
1. Authentication > Sign-in method: activa Anonymous si todavía no está activo.
2. Realtime Database > Rules: permite lectura autenticada en teamIntroOverlay y escritura solo a usuarios autenticados. Adapta las reglas a las reglas existentes, NO las reemplaces sin revisar, porque podrías afectar marcador/publicidad.

Ejemplo de regla SOLO para añadir al mismo nivel que las reglas actuales:
"teamIntroOverlay": {
  ".read": "auth != null",
  ".write": "auth != null && auth.token.firebase.sign_in_provider != 'anonymous'"
}
La expresión distingue el inicio de sesión anónimo del inicio de sesión con cuenta. Aun así, lo más seguro es restringir escritura al UID administrador. Integra este bloque en las reglas existentes, no reemplaces todas las reglas sin revisarlas.

USO
1. Abre control-equipos.html en el segundo celular e inicia sesión con la cuenta administradora de Firebase ya existente.
2. Escribe ambos nombres, carga los escudos desde la galería.
3. Pulsa “Guardar y MOSTRAR presentación”.
4. En Larix agrega una fuente Web/Browser independiente con la URL de overlay-equipos.html y ajusta el encuadre a 16:9.
5. Para retirarlo, pulsa “OCULTAR presentación” desde el segundo celular.

NOTA SOBRE SEGURIDAD
Los HTML reutilizan la configuración pública del proyecto Firebase existente. La seguridad real depende de Authentication y las reglas de Realtime Database. La lectura anónima debe estar habilitada y la escritura debe restringirse al administrador. Verifica las reglas antes de usarlo en directo.
